# MVP

Le MVP doit poser une base simple, propre et evolutive pour une plateforme B2B de gestion de demandes techniques. Les ecrans peuvent simuler les parcours avec des donnees mockees et des objets fictifs, sans pretendre fournir une securite ou un stockage sensible reels.

## Inclus

- pages publiques ;
- structure applicative propre ;
- premiers elements de design system ;
- dashboards simples ;
- creation de demande simulee ;
- espaces prevus pour chef de projet, dessinateur et admin ;
- anticipation des futures permissions.

## Exclus

- paiement, Stripe, escrow ou abonnement ;
- matching automatique IA ;
- visio native ;
- application mobile ;
- marketplace ouverte ;
- systeme d'encheres ;
- authentification reelle ;
- upload reel de fichiers sensibles ;
- stockage ou exposition de documents projet reels.
